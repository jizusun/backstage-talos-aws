# Platform Engineering Harness Blueprint

Welcome to the documentation for the Platform Engineering Harness Blueprint — a GitHub template for building infrastructure test harnesses around Terraform/OpenTofu projects.

## Getting Started

```bash
curl https://mise.run | sh
mise install
mise run lint
mise run test:unit
mise run test:integration
```
